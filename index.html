Connect GitHub

This is a GitHub access token, not your NVIDIA or GitHub password. It lets this website update the shared Users list. Only your YousefMahajna GitHub account can save.

  1. Create a GitHub token for your YousefMahajna account.
  2. Choose Only select repositories → interconnect-process-lab. Set repository permission Contents → Read and write, then generate the token.
  3. Paste it below and click Connect account. Then you can use Save changes repeatedly while this page stays open. Do not paste it into chat.

The token is sent only to GitHub and kept in page memory while connected. It is never saved in browser storage. Refreshing, disconnecting, or changing email ends the connection. This is separate from Codex.
